## 🎙 Voice Pill v1.0

Голосовой ввод для Windows 11 в стиле встроенного: плашка сверху, всё офлайн.

### Фичи

- **Win+H** — запись, ещё раз — распознать и вставить в активное поле
- Собственный низкоуровневый хук клавиатуры: **Пуск не открывается, Win-комбинации не ломаются**
- Авто-определение языка: русский и английский (🇷🇺/🇬🇧 на плашке)
- Плашка не забирает фокус, вставка в окно где курсор
- Автозапуск с Windows, работает во всех приложениях
- Распознавание полностью локальное (faster-whisper), без интернета и подписок

### Фиксы по ходу разработки

- Убрана глючная библиотека keyboard — Win-клавиша больше не умирает
- Вставка гарантированно идёт в окно, где был курсор
- Ускорено распознавание (cpu_threads по всем ядрам, без контекст-условия)
- Перехват системного Win+H без открытия меню Пуск

### Откат

Удалить папку с программой и ярлыки — ни одного изменения в реестре.
