# 🎙 Voice Pill — голосовой ввод на Whisper для Windows

Локальный голосовой ввод в стиле Windows 11: тёмная плашка сверху по центру экрана,
Win+H — сказал, Win+H — текст вставился в активное поле. Всё работает офлайн,
ничего не отправляется в интернет.

## Возможности

- **Win+H** — показать плашку и начать запись (системный хоткей перехватывается)
- **Win+H** ещё раз — остановить запись, распознать и вставить текст через Ctrl+V
- Плашка **не забирает фокус**: клик по ней не мешает работе в целевом окне
- Работает в любом приложении: чаты, браузер, редакторы
- Автозапуск с Windows, стартует скрытым
- Распознавание полностью локальное (faster-whisper, модель `base`)

## Установка

1. Нужны Python 3.10+ и ffmpeg в PATH
2. Установить зависимости:

```bash
pip install faster-whisper sounddevice keyboard pyperclip
```

3. Запустить `voice_pill.py` через `pythonw` (без окна консоли)

Готово — жми **Win+H** и говори.

## Настройка

В начале `voice_pill.py`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `MODEL_SIZE` | `"base"` | модель Whisper: `tiny`/`base`/`small`/`medium` — больше = точнее и медленнее |
| `LANGUAGE` | `None` | `None` — авто-определение (русский и английский); можно `"ru"` или `"en"` принудительно |

## Откат

Ни одного изменения в реестре. Полный откат:

- удалить папку с программой
- удалить ярлык из `shell:startup` (если добавляли)
- `pip uninstall sounddevice keyboard pyperclip faster-whisper` (по желанию)

## Структура

```
voice_pill.py       — основная программа (плашка + хоткей + Whisper)
Голосовой ввод.bat  — запуск в один клик
```
